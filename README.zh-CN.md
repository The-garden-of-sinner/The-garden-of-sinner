### `~/src`

* ✦ **[MDAP](https://github.com/The-garden-of-sinner/MDAP)** `PyTorch` `RecBole-CDR` `WISE`
  > 代表性算法研究工作（*Multi-view Disentangled and Adaptive Preference Learning for Cross-Domain Recommendation*）。针对跨域推荐中的偏好混杂与负迁移问题，设计了多视图特征解耦与自适应偏好迁移机制，在多个跨域基准数据集上验证了有效性。

* **[token-trace](https://github.com/The-garden-of-sinner/token-trace)** `Python` `LLM Observability`
  > 希望让大模型 API 调用不再是“黑盒”而编写的轻量级追踪工具，专注于多轮对话与复杂工作流下的 Token 消耗统计与调用链路观测。

* **[SuperV-cliphist](https://github.com/The-garden-of-sinner/SuperV-cliphist)** `Linux` `KylinOS` `Utility`
  > 为了在银河麒麟（KylinOS）等国产信创 Linux 环境下获得顺手的 `Super+V` 剪贴板历史体验而编写的轻量级桌面工具。
